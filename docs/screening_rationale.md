# 筛查任务设计说明

本工具包含三个家庭可操作的早期筛查任务：汉字识别、快速自动命名、声韵母重组。三个任务用于观察儿童在简体中文 / 普通话阅读相关能力中的表现，不用于下结论。

## 为什么不能用于诊断

阅读障碍的专业判断需要综合标准化测验、长期学习表现、临床或教育心理访谈、学校资料、家庭观察、排除其他影响因素等多种证据。本工具只覆盖少量任务，且由家长在家庭环境中施测，无法控制所有变量。

因此，本工具只能提供：

- 早期风险提示；
- 家庭观察线索；
- 与老师或专业人员沟通时的参考材料。

不能提供：

- 诊断结论；
- 教育安置依据；
- 医疗决策依据；
- 完整能力评估。

## 任务一：汉字识别

汉字识别任务包含 150 个汉字，观察儿童对常见汉字的认读表现。

该任务关注：

- 汉字字形识别；
- 字形到读音的提取；
- 汉字形、音、义整合中的基础表现；
- 是否出现大量形近字、同音字或猜读现象；
- 朗读过程是否明显卡顿、跳过或回避。

家长只记录儿童第一次读出的结果，不提示、不纠正。

## 任务二：快速自动命名

快速自动命名任务包含数字命名和图片命名。材料本身较熟悉，目的不是考察知识难度，而是观察儿童看到视觉符号后，快速提取名称并连续说出的速度和稳定性。

该任务关注：

- 视觉符号到口语名称的快速连接；
- 连续命名的速度；
- 是否出现跳行、漏读、重复、自我纠正或长时间停顿；
- 注意和执行过程中的稳定性。

当前该任务只记录用时和备注，不参与综合分，也不设置单独风险阈值。

## 任务三：声韵母重组

声韵母重组任务包含 16 道题，观察普通话声母、韵母和声调的加工能力。

该任务关注：

- 能否分辨声母；
- 能否提取韵母和声调；
- 能否把声母和韵母声调重新组合；
- 对普通话音节结构的操作能力。

该任务不是拼音知识考试。家长应先确认儿童理解示例，再开始逐题记录。

## 当前未覆盖的能力

本工具尚未覆盖：

- 语素意识；
- 正字法意识；
- 偏旁部首和部件位置加工；
- 阅读流畅性；
- 阅读理解；
- 书写错误和听写表现；
- 课堂长期表现；
- 家长 / 教师量表；
- 专业访谈和标准化测验。

报告页应提醒家长：分数只是一次任务表现，需要结合长期阅读和学习表现理解。
