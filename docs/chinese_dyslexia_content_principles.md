# 中文阅读障碍内容设计原则

本项目面向简体中文 / 普通话语境下儿童，内容设计不能直接套用英文 dyslexia 材料。

## 为什么不能直接照搬英文材料

英文属于拼音文字，许多英文阅读困难材料强调：

- letter-sound correspondence；
- phonics；
- spelling；
- alphabetic decoding；
- sight words；
- letter reversal，例如 b/d 混淆。

这些内容可以帮助理解阅读障碍作为神经发育相关学习困难的大框架，但不能直接成为中文儿童阅读困难筛查的核心任务。

## 中文阅读的关键特点

中文阅读涉及：

- 汉字字形识别；
- 汉字读音提取；
- 字义和词义理解；
- 形、音、义整合；
- 偏旁部首和部件位置；
- 形旁、声旁线索；
- 同音字和形近字辨析；
- 普通话声母、韵母、声调加工；
- 语素意识；
- 正字法意识；
- 快速自动命名；
- 阅读流畅性和阅读理解。

## 本项目的内容边界

当前三个任务主要覆盖：

- 汉字认读；
- 快速自动命名；
- 声韵调加工。

它们不能代表完整中文阅读能力，也不能覆盖所有阅读困难表现。

## 页面文案原则

页面面向家长，应做到：

- 语言温和；
- 不贴标签；
- 不制造恐慌；
- 不把一次筛查等同于专业判断；
- 不默认所有阅读困难都是阅读障碍；
- 明确提示可与老师和专业人员沟通。

## 推荐使用的表达

- “提示风险”
- “建议关注”
- “建议进一步评估”
- “可能需要专业人员进一步了解”
- “仅作家庭早期观察参考”
- “结合长期表现理解”

## 避免使用的表达

- 把一次筛查写成专业判断。
- 把孩子直接贴上疾病标签。
- 承诺训练可以解决所有问题。
- 暗示一次测试即可判断。
- 暗示分数低就等同于阅读障碍。
