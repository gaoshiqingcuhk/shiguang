# 家长和教师观察清单

本清单用于整理后续页面和材料可使用的观察维度。它不是量表，也不用于打分或下结论。

## 家长观察建议

家长可以连续观察一段时间，记录具体行为，而不是只凭一次测试判断。

建议记录：

- 孩子阅读任务发生的日期和场景；
- 阅读材料的大致难度；
- 孩子的身体状态和情绪状态；
- 具体错误类型；
- 是否需要反复提醒；
- 是否明显逃避阅读；
- 与口头表达相比，书面表现是否明显吃力；
- 老师反馈是否一致。

## 低年级常见观察点

- 学拼音明显吃力；
- 声母、韵母、声调容易混淆；
- 认字速度慢；
- 生字记忆困难；
- 形近字混淆；
- 同音字混淆；
- 听写错误多；
- 朗读时跳字、漏字、猜字；
- 读过的字很快忘记；
- 容易因为阅读任务焦虑或抗拒。

## 中高年级常见观察点

- 阅读速度明显慢；
- 读完文章抓不住主要内容；
- 语文作业耗时很长；
- 需要家长大量陪伴才能完成阅读任务；
- 作文或书面表达明显弱于口头表达；
- 长篇文字阅读容易疲劳；
- 长期回避阅读；
- 阅读理解题经常答非所问；
- 听写和错别字问题持续存在。

## 教师课堂观察点

教师可以关注：

- 朗读慢；
- 经常跳字、漏字、添字；
- 读错形近字；
- 混淆同音字；
- 新字学习和保持困难；
- 听写错误多且类型反复；
- 课堂阅读理解明显吃力；
- 口头回答尚可，但书面表现明显弱；
- 需要比同伴更多时间完成阅读作业；
- 对阅读任务表现出回避或挫败。

## 沟通建议

家长和教师沟通时，可以带上：

- 筛查报告截图或打印件；
- 听写本或作业样本；
- 朗读时的错误记录；
- 孩子近期阅读材料；
- 家长观察到的情绪和行为变化。
