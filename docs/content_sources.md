# 内容依据与待核查资料清单

本项目面向简体中文 / 普通话语境下 7-12 岁儿童的阅读困难早期筛查。当前运行环境未进行联网检索，因此本文件不列出未经核查的论文题名、作者、期刊、DOI 或 URL。

页面文案采用保守、非诊断性表达：只说明本工具观察哪些阅读相关能力，提示哪些表现值得关注，并建议家长结合长期表现和专业人员意见理解结果。

## 当前内容依据的处理原则

- 不直接照搬英文 dyslexia 筛查材料。
- 不把英文拼读、字母反转、拼写困难等内容作为中文筛查核心。
- 强调中文阅读涉及汉字形、音、义整合。
- 强调普通话声母、韵母、声调加工与阅读相关表现。
- 强调语素意识、正字法意识、快速自动命名等中文阅读研究常关注的能力。
- 不写具体患病率、诊断准确率或训练效果百分比，除非后续有可靠资料核查。
- 不承诺效果，只写支持、观察、训练和进一步评估。

## 后续建议人工核查的资料类型

### 诊断边界和专业评估框架

- DSM-5 / DSM-5-TR 中 Specific Learning Disorder 的定义、阅读困难表现和诊断边界。
- ICD-11 中 Developmental learning disorder with impairment in reading 的定义和边界。
- 专业评估中通常需要的标准化测验、临床访谈、学校表现和长期观察资料。

用途：完善关于页面、免责声明和报告页的专业边界说明。

### 中文儿童阅读障碍研究

- 中国大陆 / 汉语 / 普通话儿童发展性阅读障碍研究。
- 中文儿童阅读困难中的汉字认读、音韵意识、语素意识、正字法意识、快速自动命名研究。
- 中文儿童阅读障碍患病率研究。
- 普通话低年级儿童阅读困难筛查或评估工具研究。

用途：完善首页、知识库和筛查任务依据说明。

### 中文阅读相关量表和工具

- DCCC 儿童汉语阅读障碍量表相关研究。
- 低年级发展性阅读障碍筛查工具相关研究。
- 家长和教师观察量表相关研究。

用途：未来如果增加家长 / 教师观察问卷，需要先核查量表版权、适用年龄、评分方式和授权边界。

### 教育和汉字材料依据

- 教育部《义务教育语文课程标准（2022年版）》。
- 《通用规范汉字表》。
- 小学语文识字、写字、阅读能力要求相关资料。

用途：完善汉字材料选择、年级解释、干预资源规划。

### 干预研究与实践资料

- 中文儿童语素意识训练研究。
- 音韵意识训练研究。
- 正字法意识和偏旁部件训练研究。
- 阅读流畅性和阅读理解支持研究。
- 家庭亲子阅读与学校支持策略资料。

用途：扩展干预资源页和后续材料下载体系。

## 页面中当前不应写入的内容

- 未经核查的具体患病率。
- 未经核查的测验敏感性、特异性或准确率。
- 未经授权的标准化量表题目。
- 未经核查的论文标题、作者、期刊、DOI 或 URL。
- 直接给孩子贴疾病标签或承诺训练效果的表述。
