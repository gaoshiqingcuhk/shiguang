# 隐私、知情同意与免责声明文案

本文件整理项目中的隐私和免责声明原则，便于页面文案保持一致。

## 隐私原则

当前项目：

- 无登录；
- 无后端；
- 无数据库；
- 无上传接口；
- 无音频、视频、照片采集；
- 无埋点；
- 无统计 SDK；
- 数据只保存在浏览器内存状态中；
- 刷新或关闭页面后当前筛查进度会丢失。

## 推荐短文案

本工具在浏览器本地运行，不需要登录，不上传测试数据。儿童年龄、年级、计时和作答记录只保存在当前页面的临时状态中。刷新或关闭页面后，当前筛查进度和结果会丢失。

## 知情同意重点

家长开始筛查前应理解：

- 工具仅作家庭早期观察参考；
- 家长负责施测、计时和记录；
- 家长不得提示或引导答案；
- 结果不能作为专业评估结论；
- 如需保留报告，可截图或使用浏览器打印功能；
- 刷新页面会丢失当前数据。

## 免责声明重点

本工具不能替代：

- 医疗评估；
- 心理评估；
- 语言治疗评估；
- 教育心理评估；
- 特殊教育评估；
- 学校长期观察和专业判断。

本工具结果不应作为：

- 教育安置唯一依据；
- 医疗决策唯一依据；
- 干预方案选择唯一依据；
- 对儿童能力下结论的依据。

## 如果未来增加本地持久化

如果未来增加 `localStorage` 或 `IndexedDB`：

- 知情同意页必须说明数据会保存在本设备浏览器中；
- 需要提供清除本地数据的方式；
- README 和关于页面也要同步更新；
- 不应继续写“关闭页面后数据即被清除”。
